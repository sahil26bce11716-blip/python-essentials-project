# Python Essentials Project

## 📌 Project Description

This project is created to practice and demonstrate the basic concepts of **Python programming**. It covers fundamental programming concepts such as variables, input/output, conditional statements, loops, functions, lists, and basic problem-solving.

The purpose of this project is to build a strong foundation in Python programming.

## 🎯 Objectives

* Learn the basics of Python programming.
* Understand variables and data types.
* Use conditional statements.
* Understand and implement loops.
* Work with lists and arrays.
* Create and use functions.
* Solve basic programming problems.
* Improve logical and problem-solving skills.

## 💻 Example

```python
a = [1, 2, 3, 4, 5, 6]

even = 0
odd = 0

for i in a:
    if i % 2 == 0:
        even += 1
    else:
        odd += 1

print("Even numbers =", even)
print("Odd numbers =", odd)
```

### Output

```text
Even numbers = 3
Odd numbers = 3
```
